# Vibe Coding Prompt Templates: OBS Background Removal Plugin

这些模板用于让人类把创意、需求和约束讲清楚，让 Agent 主导探索、设计、实现和验证。使用时保留成功标准、边界、验证方式和交付格式。

## Product Discovery
```text
你是 OBS Background Removal Plugin 的产品负责人和工程负责人。请先帮我澄清需求，不要直接写代码。
目标：<一句话目标>
用户：<目标用户/角色>
场景：<用户从哪里开始，到哪里算成功>
约束：<权限、数据、性能、上线时间、合规、安全>
请输出：
1. 关键澄清问题，最多 5 个
2. Mini-PRD 草案
3. 非目标和边界
4. 可测试验收标准
```

## Technical Plan
```text
请基于当前仓库实际结构做技术方案，不要假设不存在的模块。
需求：<粘贴 Mini-PRD 或任务描述>
要求：
1. 先探索文件、模块、命令和现有同类实现
2. 说明影响面、接口契约、数据影响、异常场景和回滚方式
3. 给出最小实现切片和验证 profile
4. 标记需要人工确认的 CRITICAL 操作
```

## UI/UX Work
```text
请以高级 UI/UX 设计师 + OBS 插件开发视角处理这个界面任务。
目标体验：<用户感受/业务目标>
参考风格：<可选>

```

## Bug Fix

## Release Readiness
```text
请按 release profile 评估是否可以发版。
必须检查：未提交改动、依赖和 CMakeCache、cppcheck、ctest、编译检查、cmake build、关键业务流、临时资源清理、安全敏感日志。
请明确回答：可以发版 / 不可以发版 / 有条件发版，并列出证据和阻塞项。
```
